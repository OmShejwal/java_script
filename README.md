# JavaScript Practice Repository

A comprehensive collection of JavaScript learning projects and practice exercises covering fundamental concepts to advanced techniques.

## 📚 Project Overview

This repository contains my JavaScript learning journey, including:

### Core Concepts
- **Variables & Data Types** - Working with different variable types and operations
- **Functions** - Function declarations, expressions, and advanced function concepts
- **Objects** - Object creation, manipulation, and methods
- **Arrays & Loops** - Array methods and iteration techniques

### Interactive Projects
- **Rock Paper Scissors Game** - Classic game with DOM interaction
- **Todo List Application** - CRUD operations with DOM manipulation
- **DOM Projects** - Various DOM manipulation exercises

### Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
